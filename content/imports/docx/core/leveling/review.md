# 拂晓主要玩法

拂晓的主要玩法可以分为主线推图、困难推图、主线打捞、活动打捞、档案打捞、防卫战、争锋竞技场、遭遇战、无尽海域九个部分，以这些玩法为标准，可以划分总BOX，进而针对你主要感兴趣的玩法进行练级。下面从练度角度简单介绍各个玩法：

①主线推图、困难推图、主线打捞：单点出战，即只需一队舰灵、只打一场、能通关即可、通关概率无所谓、通关评级影响不大、对船型国籍等基本无要求，因此对练度要求相对较低；

②活动打捞、档案打捞、防卫战：连续出战，即需要1-2队舰灵、要打多场战斗（如中途战败则获取奖励大大减少），所以配队要求稳、求高通过率，对船型国籍有一定要求，因此练度要求相对较高；

③争锋竞技场、遭遇战：含有PVP或PVE争排名的要素。如只想获取保底奖励，对练度要求低于打捞活动和防卫战；如想获取较好排名，要有成体系的高练度BOX。但注意，保底奖励占了两种玩法的大多数奖励，且练度很低就能拿到，排名的额外奖励大多数为荣誉性质的，因此鼓励萌新大胆参与拿到保底。

④无尽海域：选择60艘舰灵组成活动BOX，进行若干场爬塔性质战斗。低层纯福利，1-30层汇集了大部分奖励，31-60层汇集了剩下少部分奖励。61层以上的高层难度迅速迭代，仅有荣誉性质奖励，主打挑战自我，属于大后期玩法。

# 争锋竞技场舰灵推荐

争锋分为金、紫、蓝三场，每场分小、中、大队、共计队。

笔者推荐萌新优先级如下：

金小中&gt;金大&gt;紫小中&gt;紫大&gt;蓝

原因如下：

萌新的竞技场玩法主要是“追”，即如何用最少的资源、最低的试错成本、最低的练级难度去获取一套可堪一用的阵容；

小、中船比起大船，练级消耗低很多，练一队大船队的资源能练一队小船加半队中船。

金场小、中队与紫场小、中队有较高的重合度，而金场大队与紫场大队几乎零重合度；

蓝场练级难度太大，紫场练级难度略低于蓝场，但也远高于金场；

金场舰灵在其他玩法中强度一般也很高，就业范围更广；

某个舰灵刚练满就从顶分队中被踢出的系统性风险是永远无法回避的，哪怕现在练的舰灵在未来只能组出“可堪一用”的一线至二线阵容，也足以笑傲5%了。

# 练船的主要目标

练船的主要目标是经验和好感度，通过分配旗舰和MVP的归属，会改变一次练船后的经验和好感度获取的分布。（见后文）

练船的次要产物是舰灵打捞、强化素材、活动代币等。（见后文）

练船一般采用高级带低级、先练带后练的策略，因此还要注意能够可持续循环，非XP玩家更要警惕青黄不接问题。（见后文）

一般来说，一个优秀的练级策略要能够兼顾上述三点，下面介绍的“老板-打手循环”可以给广大萌新作为参考答案。

# 核心策略：老板-打手循环

“老板-打手循环”是笔者总结了众老玩家的练级思路，并在实践中检验过的核心练级策略，举例解释如下：

Step.1 打手A（如级槽）带着老板B（如级槽、旗舰）练级，打手A提供输出（获得倍经验和倍好感度）、老板B坐享经验和好感度（获得倍经验和倍好感度）。

Step.2 当老板B到达一定练度（如级槽）之后，飞升成为打手B，带着新的老板C（如级槽、旗舰）继续练级，此时打手A基本能达到级、永恒好感度。

Step.3 不断循环，老板C飞升为打手C，再带老板D。老板D飞升为打手D，再带老板E……

Step. 最终将会获得一个都达到级、槽、永恒好感度的BOX。

在这一循环中，老板是指没有独立练级能力的舰灵，打手是指有基本独立练级能力的舰灵。因此老板与打手的区别主要是在当前练级点的输出能力和生存能力。这意味着从老板到打手的“飞升门槛”也并非固定，影响这一门槛的主要有以下要素：

Ele.1 练级点：目前有活动和主线两种练级点，收益基本相当。一般来说，在主线练级时对生存能力的要求可以适当降低，在活动练级时对输出能力的要求可以适当降低

Ele.2 等级与好感：拂晓PVE玩法存在等级压制，升级能显著提高输出和承伤能力。越高的好感阶段能提供越高的增伤和减伤，婚后的额外装备槽能够增加可装备数量，提供大量属性。

Ele. 舰灵特性：舰灵的攻击模组、弹种、面板属性等，如不适合PVE场景或在当前练级点表现较差，“飞升门槛”也会相应提高；反之亦然。

Ele. 外部属性：装备、羁绊、航向、阵型等等。（这也是我们规划练级策略时最可控的，后续会详谈）

# 为什么是级？

在拂晓的各种玩法中，级已能够在JJC、遭遇战中形成可靠的战斗力。而升级所需经验随等级递增，从下表可知，级以后，升级的边际收益开始强烈递减。

| 1-40 |  | % | % |
| 40-50 |  | % | % |
| 50-60 |  | 1.0% | % |
| 60-70 |  | 8% | 5% |
| 70-80 |  | % | 1% |
| 80-90 |  | % | 5% |

因此，平铺级的收益一般来说会远高于追求个别满级。

值得一提的是，在打捞活动中，由于带路要求的强制点名、萌新BOX偏科等问题，部分高级甚至满级船会不得不登场，而现在的打捞活动经验量非常可观，足以跻身最顶级的练级点之一。这就意味如果仅追求个别满级的话，可能会导致一场打捞活动溢出巨量的经验和好感度。

另外，平铺级也是对青黄不接问题最简单无脑的兜底式解决方案。（见后文）

最后，80-90（目前尚未开放级）的那部分经验，可以在活动打捞、主线打捞（尤其是部分蓝、紫打捞点）、防卫战中补齐。或者，当级舰灵数量较为可观后，也可以单独把一部分级的争锋、遭遇战舰灵优先升级到级。

# 论经验和好感度

单倍出击最高战果胜利后，非旗舰获取倍好感度（），旗舰获取倍好感度（），MVP归属对好感度的获取无影响。旗舰和MVP都会获得额外50%经验，可乘算叠加，即旗舰+MVP获取倍经验。非最高评价（主线为非星、活动为非S）会较少地减少经验获取、大量减少好感度获取。

因此有以下结论：

Concl.1 当练级目标为经验最大化时，一般要控制旗舰和MVP在一艘船上；

Concl. 当练级目标为好感最大化时，一般旗舰给老板；

Concl.3 尽量保证最高评价。

一般来说，好感度在后期会先于经验溢出（多倍经验活动除外），但好感度在“老板-打手循环”中起到至关重要的作用，因此萌新务必要关注舰灵的好感度获取问题。好感度分为下图等级，其中有几个关键节点：相识（开天赋）、喜欢（开天赋）、爱（可婚）、誓约（开槽）、依偎（开槽）、守护（开槽）、至爱（开槽）、永恒（满好感）。

# 开槽与刷级

不同于等级，好感度的获取与练级点无关，且高好感度提供的战斗力加成也很显著。另外，由于目前版本，活动经验与主线经验相当，因此诞生了两条分流式练级思路：

思路：在必需的简单地图练好感度，在高经验的练级点练等级。

思路：用1+1练等级，用1+0练好感度。

我们先谈思路：在必需的简单地图练好感度，在高经验的练级点练等级。所谓必需的简单地图，是指那些必须要打、不得不打的低经验收益地图，一般是指前期主线打捞图。而高经验的练级点，目前主要指活动地狱、活动EX、18-7、19-5、19-10、20-2、20-5。

再谈思路：用1+1练等级，用1+0练好感度。所谓1+1是指前排后排，1+0是指前排可以单挑，后排无所谓。在打手等级较低时（如吹雪级星槽），她想通关20-5或活动EX，必须要有后排助力。所以这个时候，直接给吹雪控制双加成，最大化等级收益。当打手等级较高（如吹雪级星槽），这个时候她足够单挑20-5或活动EX，就可以挂一个没伤害的后排，把旗舰给后排，方便给后排开槽，有助于练级循环启动。这一部分在本章第节会有呼应。

当然，思路、并非互斥的，可以同时使用。随着版本变化，练级点的经验收益变动，思路中判定的“必需的简单地图”也会变化。

这里再补充两个常见案例：

案例1.先开槽后刷级：先在打捞活动1+0，将好感练到至爱，开启个装备槽，然后再在20-2等黄金练级点练级。（一般级槽即可当打手）

案例2.先刷级后补好感：在双倍经验期间练到很高等级，但好感没有到永恒。选择在前期主线中的蓝紫舰灵打捞图（如18-5、18-10、15-10、13-5、12-5等）、防卫战（由于等级很高，防卫战也相对成为简单地图了）等点位补好感。

# 再论强化素材、舰灵打捞和活动代币

在打捞活动的EX难度往往可以获得大量紫色强化素材（简称紫菜），根据笔者在最近活动（电影大作战）的个人统计，紫色素材的获取概率在7.75%。

图及以后以、结尾（如16-3、16-5）的困难主线地图也会掉落紫菜，每天三次。此外，热门的主线练级点（如18-7、19-5、19-7、19-8、19-10）也会掉落蓝色素材，在日积月累下也是不可忽视的。

在打捞活动和部分主线可以兼顾练船和打捞舰灵，打捞舰灵可被视为一种省油机制（退役回油），萌新可以使用保底捞船法进行主线打捞，老登也可以使用保底捞船法进行活动打捞。上表的“触发保底”一栏记录了笔者获取的保底SSR舰灵。

所谓保底捞船法，即每次出击胜利且未获取SSR品质舰灵或道具时，将会提高后续出征获取SSR舰灵或道具的概率。玩家统计发现，在出击胜利次数达到左右，下次出征获取SSR舰灵或道具的概率接近100%。保底捞船法一般用于经验收益较低的主线、以及最新上线的档案功能：

①对于经验收益较低的主线，一个经典案例就是5-10捞赤城。玩家可以在18-7、20-2等这些不会掉落SSR的黄金练船点练把，回到5-10一把捞出赤城，既能最大化经验收益、也不会在打捞进度上落后太多。

②对于档案功能，与上文类似，但一定要注意带路问题。

活动代币主要指打捞活动和补给活动的代币。打捞活动的代币掉落受部分舰灵加成，每期活动都能看到，如有意在活动练级可以凭此调整配队。

补给活动的代币仅在补给姬活动开启时于主线地图获取，越往后的地图获取量越大，第章开始掉落个，每过章掉落增加，5-9图掉落个、到图个、16-19图个。

之前的版本，补给姬惨遭削弱，硬控舰灵十几二十秒的“辉煌”再难重现，因此一般不需要额外在意。

# 论老板和打手的站位问题

在“老板-打手循环”中，老板和打手的站位也并非一成不变的，其本质是随着练度的提高，舰灵的定位会从“老板”逐渐过度到“打手”。由于好感度会先于经验溢出，适当地调整站位使老板获取旗舰、MVP双经验加成，能显著提高练级效率。由于老板在低等级时很难抢到MVP，因此一般的站位策略是：

①老板低等级时，由于老板战斗力孱弱，由打手“喂饭”给老板。一般选择打手在前、老板在后，旗舰给老板，MVP给打手；

②老板高等级时，由于老板具有一定战斗力，让老板自己输出、打手补充伤害。一般选择老板在前、打手在后，旗舰给老板，控制MVP给老板（当然打手是可以更换的）；

③随着老板的战斗力提高，可给后排打手尽量减配，或更换输出更低的打手，确保老板的MVP获取率。一般这个时候，老板就已经慢慢过渡为打手了。（能前排站住，能拿MVP，不是打手是什么？）

由于部分舰灵做打手时很难把MVP让给老板，因此可将打手分为两个部分，分别是纯打手（难以让MVP的）和补充伤害打手（可以让MVP的），对她们的使用思路也有所不同。当然，这个划分规则是弹性的，根据二者的相对练度和练级点而定。

以Z1和未改绫波在18-7的表现为例。由于Z1在18-7的前后排伤害都非常爆炸，在练中、小船时几乎无法让MVP，因此推荐让Z1作为纯打手，只带中、小船老板的低等级阶段。等到老板能够自理时，将老板置于前排、未改绫波置于后排，由绫波补充伤害，保证老板能拿到MVP的同时还具有较高的通过率。

另外，根据计算，当老板在后排时，适当卡星可以降低油耗；若老板可以通过升星在前排拿MVP，应当早点升星去前排拿MVP和旗舰双加成。

# 驳经验转移练级法

经验转移功能，指舰灵达到级并储存1800k经验后，获取的经验将会转移给队伍中的其他舰灵，公式为：

转移经验=溢出经验*溢出舰灵油耗/100

可见，溢出舰灵的油耗越高，转移的经验越多。但同时，无论转移多少，本质上都是亏油的。

因此，任何使用经验转移的练级方法都是亏油的，任何试图教萌新用经验转移练级的玩家对练级机制都没有较为细致的了解和分析、或者有其他不友善的目的。经验转移功能主要用来弥补老登使用经验溢出船打捞时承受的部分经验亏损。

# 青黄不接问题

所谓的青黄不接，即因为练级规划不合理，导致部分在练级点表现抢眼的舰灵达到级，而其他舰灵只停留在50-60级的尴尬情况。在此种情况下，玩家要么捏着鼻子用满级舰灵带队（经验溢出）、要么让低等级舰灵采用1+2练级（练级获取效率低）、要么用GE强拉一个打手。

一般来说，只要采用笔者推荐的老板-打手循环策略进行练级，就可极大程度避免此问题。倘若出现，因为笔者的练级策略推荐把打手练到级即停止，因此也可用级打手继续带队低级舰灵，也即前文提到的兜底式解决方案。

还有一类“青黄”不接，指的是随着高稀有度舰灵（黄）逐渐练完，低稀有度舰灵（青）的练级难度逐渐增加。这一问题主要通过提高练级技术、增大资源投入（如GE、礼物、强力装备、沙滩、远征吃经验等）来解决，用级的高稀有度舰灵也可帮低稀有度老板尽快度过低等级的艰难期（又是一种兜底）。

与之类似的，也有将某一类舰灵全部练完后，因为活动需求或练级点变迁而不得不上满级舰灵，从而导致经验溢出的情况。典型的情况是因为沉迷于小船的低油耗，导致小船练差不多了大船一点没动的情况。在此，笔者建议玩家在脱离了开荒期的艰难阶段后，尽量对不同稀有度、不同种类的舰灵平铺式练级。

# 以18-7为例的练级技巧分享

如前所述，18-7、20-2是适合清杂舰灵的一系列练级点，练级技巧大同小异。其中，18-7作为与玩家见面最早、门槛最低的练级点，以其为例分享清杂舰灵的练级技巧，无疑是最为合适的。

从输出面分析，输出压力主要集中在中甲战巡，此外提高对轻甲的输出能力能极大缓解生存压力。

## Tip 注意甲弹克制

选择通常弹、高爆BB、高爆CA出战，可以快速清杂、显著提高生存机率。此外，以下弹种的舰灵出战，也能够有效降低练级门槛。

## Tip.2 提高索敌、尽量达到T优

一般索敌达到索敌线的倍即可以稳定T优，对于18-7来说就是点索敌。T优可提供大量增伤减伤加成。

索敌方面，推荐萌新使用紫雷达和入坑赠送的勋章（强化越高越好，与马桶同索敌），一般上2-4个即可；后期可使用勋章、马桶，一般上个。

由于紫雷达索敌较低，萌新短期内又很难拿出两个金装，因此可以考虑用1+2阵容练级。两个紫雷达和个勋章可提供的索敌，剩余三个舰灵凑够索敌还是很容易的。

航系索敌很高，如打手为航系，一般也可以减少一个雷达需求（因为伤害溢出机制，后排航系容易抢MVP，如果使用的话要注意这一点）。这里额外推荐独角兽（CVL）后排，有一定输出和不俗奶量，但不至于抢MVP，鱼雷补刀中甲战巡很好用，且油耗尚可、索敌较高，主线可打捞。

额外提醒，紫装性价比极高，强化消耗很低、紫装一般强于金彩装。一般来说，多准备几个紫装玩起来会很舒服，不会亏的，后期拆掉紫装也可返还80%的升级材料和晶币。

## Tip.4 提前开槽

雷达和马达均只能装备在设备位，舰灵达到至爱好感后可开启第二个设备位，因此槽舰灵往往可以在轻松T优的同时给前排携带马达。这也是第二章第节介绍 “先开槽后刷级”的练级思路的重要原因。

对于萌新来说，在二者不可得兼的情况下，推荐优先满足T优条件。

若依然有生存压力，还可尝试将索敌控制在推荐索敌的75%到倍之间（157~208），打返航战，并给前排带马达。

若依然有生存压力，可以考虑用1+2阵容来同时保障索敌和机动。这样打手可解放一个设备位放马达，通过凹闪避来极大降低通过门槛。

反之，若提前开槽，有槽打手和槽老板，就意味着练级时极大可能少上一个舰灵，达成1+1的最优解。

## Tip.5 颗秒

不难想见，如果能做到一炮秒杀（常见于战列、战巡、重炮、重巡、轻巡）、小水管连喷瞬秒（常见于驱逐）、一机秒杀（常见于航系），无疑可极大降低练级门槛。（鱼雷由于命中率不稳定，一般不考虑鱼雷颗秒情况）

一般来说，颗秒极其依赖于练度，以下细节有助于尽量达成颗秒：

选择炮击最优的炮，强烈推荐驱逐的，炮击甚至高于轻巡炮，不仅能给驱逐和水母用，中、大舰灵的副炮也可选择（但要注意命中，可选择其他命中较高的防空炮、槽选手也可另一副炮带命中较高的平衡的命中debuff）。

攻伤天赋、炮伤天赋等。

强化、升星等，极大提高基础面板。

技能等级（一个技能秒也叫颗秒）。

炮弹，不过注意炮弹也占设备位，因此这一技巧可用机会比较少。

一般来说，与其作为一种降低练级门槛的方法，不如将颗秒视为一种判断是否应该去收益更高地图的标准。如前所述，18-7的练级门槛略低于20-2，一般来说如果在18-7能够达到“颗秒”或者接近“颗秒”，就可以在后面的地图轻松练级了。

# 3.19-5练级技巧分享

19-5为单Boss点，是极其擅长远距离激光和近身火海的丙级战列，甲种为重甲。

可用的策略中，大部分与18-7类似，因此赘余部分将不再详述。

## Tip.1 甲弹克制

Boss为重甲，克制重甲的主要有通常战列、穿甲战列、鱼雷、鱼雷机。

其中，通常战列更推荐在19-10练级；穿甲战列在19-10练级体验更好，但在19-5也能练（毕竟可打捞镇海和飞机蓝菜）；以鱼雷、鱼雷机为主要输出手段的舰灵则非常推荐在这里练级（鱼雷、鱼雷机伤害占比越高，练级门槛越低）。

至于其他舰灵，基本打不掉血。

## Tip.2 索敌

建议索敌，返航线、T优线。

## Tip.3 生存

Boss的激光输出极其恐怖，哪怕战列血高甲厚也很难抗住。因此还是要尽量祭出我们的次元回避金字塔。

此外，不同炮的攻击范围不一样，这意味着Boss周身的火圈对部分类型的舰灵容易造成极大伤害。

笔者亲测发现，驱逐、轻巡、重巡舰灵基本全程蹚着火圈打，战列部分时候蹚着火圈、部分时候在火圈外，航系基本不会吃到火圈。

这意味着航系的生存压力相比其他舰灵往往要小得多，因此选择鱼雷机为主要输出手段的航系，可极大降低练级门槛。

选择战列则必须有较高练度、且搭配1~2个马达或后排有奶。

## Tip.4 开槽

由于19-5生存压力较大，基本都需要给前排带马达，所以推荐至少有一个槽打手或槽老板，装备上马桶和马达。

## Tip.5 技能形态

毫无疑问，所有的AOE舰灵都不太推荐在这里练级，浪费了她们的AOE天赋。反之，单体伤害舰灵则在此处如鱼得水。

## Tip.6 后置练级法

前文提到航母后置时，特别提醒了玩家要注意后排航母容易抢MVP的问题。我们不妨转换一下思路，若采用前排擅长生存、后排擅长输出的组合，也可以轻松练级。

此处推荐如下：

擅长生存的前排：雪风、杰维斯，其他高等级驱逐

擅长输出的后排：大部分后排有伤害的战列和航系（对19-5而言，选择穿甲战列和后排鱼雷机技能的航系即可）、雷巡、雷驱等。

当然，所谓的擅长生存和输出也是相对的，这个练级组合只要满足两个条件即可：

后排拿旗舰+MVP双加成

前排能活下来

因此读者也不妨进行大胆尝试。举例来说：

笔者使用级初雪（仅装备雷达）级槽荷马组队练级。初雪的鱼雷占比较低、炮击为穿甲、且笔者未装备鱼雷和驱逐炮，因此对Boss造成伤害有限，但生存能力极强；荷马虽然等级较低，但后排穿甲炮有20%的伤害补正，轻松拿到MVP（但是忘记控制旗舰了）。

至于为何在18-7章节不做推荐，因为一般来说战列、航系的后排技能清杂效果都较差，如果控制后排拿MVP的话，大概率是超时的。

# 4. 19-10练级技巧分享

19-10的思路均与19-5类似，但前者Boss难度低了很多、且为中甲航系。

可用的策略中，大部分与18-7、19-5类似，因此赘余部分将不再详述。

## Tip.1 甲弹克制

Boss为中甲（最菜的甲），克制中甲的有一大堆。考虑到Boss为单体，因此优先推荐缺少清杂能力的舰灵在此练级。此外，通常战列和穿甲战列虽然也可在19-5练级，但19-10的门槛低很多，因此更推荐优先在此处练级。

Boss对空较高，这意味着我们的航系输出能力有限，因此有鱼雷机的航系都推荐在19-5练级。至于纯轰炸航系，练级的输出压力无疑相较其他舰灵偏高，但相同的，生存压力会偏低（战斗机可击坠敌方飞机）。

## Tip.2 索敌

建议索敌，返航线、T优线。

## Tip.3 生存

虽然Boss的输出中飞机占比极高，但我们的次元回避金字塔依然有效。

如果能够装备较多的高对空防空炮、以及选择对空较高的主副炮，则可有效击坠Boss的自爆飞机群，提高通过率。由于这些装备位和设备不冲突，且Boss攻击频率相对较低，因此有可能出现飞机击坠、炮击全闪避的无伤战果。

## Tip.4 开槽

依然是开槽可极大降低练级门槛。

## Tip.5 技能形态

毫无疑问，所有的AOE舰灵都不太推荐在这里练级，浪费了她们的AOE天赋。反之，单体伤害舰灵则在此处如鱼得水。

## Tip.6 后置练级法

与19-5部分的前文类似，不赘述。但总体上，对后置练级的需求不如19-5高。

常见的有较高练级优先级的推荐如下：

擅长生存的前排：雪风、杰维斯，其他高等级驱逐

擅长输出的后排：大部分后排有伤害的战列和航系（对19-10而言，选择通常战列、穿甲战列和后排轰炸机技能的航系即可）

当然，所谓的擅长生存和输出也是相对的，这个练级组合只要满足两个条件即可：

后排拿旗舰+MVP双加成

前排能活下来

因此读者也不妨进行大胆尝试。举例来说：

笔者使用级小拉菲（仅装备雷达防空炮）级槽荷马组队练级。小拉菲的鱼雷占比较低、炮击为高爆、技能的高平炮对中甲衰减较大且笔者未装备鱼雷和驱逐炮，因此对Boss造成伤害有限，但生存能力极强（图中DPS统计包括打飞机伤害，所以有较大虚高）；荷马虽然等级较低，但后排穿甲炮有30%的伤害补正，轻松拿到MVP。

# 5. 20-5练级技巧分享

20-5的思路与19-10一脉相承。Boss为双乙级航母，有“进水”控制效果，且能炸后排。此外，小怪也会干扰输出。因此，尽管20-5的Boss比19-10的Boss更脆，输出压力较19-10却并不低、生存压力更高了不少。总得来说，20-5是所有点位中练级难度最大的。

可用的策略中，大部分与前文类似，因此赘余部分将不再详述。

## Tip.1 甲弹克制

Boss为中甲（最菜的甲），克制中甲的有一大堆。如果只看Boss，本关卡既适合单体舰灵，也适合AOE舰灵。且Boss的对空不像19-10高的那么离谱，这就意味着航系也能在此处练级。

值得注意的是，图中会在168S刷新只驱逐，且90S前不再刷新。小怪会干扰打Boss、。一般在打死一个Boss或补给姬后会概率锁定到小怪上。因此，本关卡对舰灵的搭配有一定要求。但这带来了一个额外的优点，那就是哪怕不擅长对抗中甲的舰灵，在本关卡也有用武之地（也可以蹭经验）。

以下是解决小怪干扰的方案：

前排选择高频输出打手，如通常轻巡、通常重巡、战列等能快速解决小怪的船。

前排选择AOE舰灵，如拉菲家族等，连Boss带小怪一起打。

若前排为航这样攻击前后摇较长的舰灵，后排要配合高频技能的舰灵，如Z1（9S）、谢菲尔德（9S）、独立（8S）、未改列克星敦（10S）等。

若采用后置练级法，前排需要较高练度，因为支援技不能稳定锁定Boss，有可能打到小怪身上。推荐选择高爆舰灵，可以降低对Boss伤害，还能较好地清理小怪。

## Tip.2 索敌

建议索敌，返航线、T优线。

## Tip.3 生存

Boss的技能“航母高射炮”能让我方进水，硬控秒钟。一旦被控制住，很容易吃满“地毯式轰炸”暴毙。且小怪也有一定输出，因此次元回避金字塔非常重要。

如果能够装备较多的高对空防空炮、以及选择对空较高的主副炮，则可有效击坠Boss的自爆飞机群，提高通过率。

## Tip.4 开槽

依然是开槽可极大降低练级门槛。

## Tip.5 技能形态

AOE舰灵和单体舰灵都可在此处练级，总体上讲，AOE舰灵的体验会更好。

## Tip.6 后置练级法

20-5的后置练级法操作较困难，原因有二：

支援技不能稳定锁定Boss，容易打到小怪身上。而为了较好地清理小怪，提高支援技命中率，就要提高前排练度，导致后排更难拿到MVP。

2.Boss的飞机会炸后排，需要前排防空较高，否则后排活不下来。而除了部分天生的高防空驱逐，其他舰灵想要有高防空，就要有高练度，这又会导致后排难拿到MVP。

3.Boss的控制、轰炸小连招刚需高机动，闪避不过去就会被秒杀。而除了部分天生高机动驱逐，大部分驱逐想要高机动，就要有高练度，这再次会导致后排难拿到MVP。

因此，如无必要请不要考虑在此点位使用后置练级法。如果非要使用，推荐前排选择高练度驱逐，或者低练度的天生数值怪驱逐（点名丹阳，航母级别的对空，驱逐顶级的机动，技能一开更是啊……，而且高爆弹，打Boss-40%，不容易抢MVP），否则很难在双航母面前保全自己和后排。

# 活动与档案练级技巧分享

活动与档案是目前的最优练级点。由于不同活动、档案的带路要求不同，无法像主线练级点那样给出明确的克制办法。在此，仅列出一些通用性办法。读者也可根据敌舰分布，参考前面主线练级点的克制办法选择舰灵。

## Tip.1 自奶与后排奶

若打手的练度相对较低（如星级槽打EX），一般以选择自回打手为佳，或在后排带一个奶。

如打手的练度相对较高（如星级槽打EX），可选择无自奶打手、也可不带后排奶，但要注意是否全程S通关（非S通关会少量亏损经验、大量亏损好感度）。

常见的有较高练级优先级的前排自奶、后排奶如下：

后排奶：哈曼、女灶神、吸血鬼、杰维斯、镇海、独角兽、卡约（不常用）、应瑞（生存拐）、伦敦、奥马哈（生存输出两用拐）、长良（生存拐）、火力（须暴击、必选梯形阵）；

前排自奶：小拉菲、大拉菲、雪风（超时警告）、明尼、萨拉托加（必须改造）、黎塞留（必须改造）、重庆（三星天赋）、逸仙（三星天赋）、独角兽、杰维斯、响、卡约、吸血鬼（须暴击、必选梯形阵）、新奥尔良、利托里奥、企业、沙恩、布列塔尼、恰巴耶夫（五星天赋）、火力（须暴击、必选梯形阵）、甘古特（五星天赋）、蒙彼利埃（三星天赋）、独立（三星天赋）、唐斯（最好有信物）、南达科他（刚需信物）。

活动练级路线中一般存在回复点和油点，优先级来说，走油点&gt;走回复点。油点会给玩家回复前一战油耗的一半，回复点回复出战队50%血量。以电影大作战EX的战油点路线为例，等同于用战的消耗打了战。

活动试用可大幅降低练级门槛，但要注意，活动试用不提供天赋、强化、技能等级和好感度的效果，因此比正常练上来的船强度弱不少，且油耗一律按照试用星级和等级收费。在舰灵练度较高后，推荐关闭活动试用。

多数航系清杂能力较弱，而单发伤害较高，若放在前排，建议搭配清杂能力较强的后排舰灵练级（如Z1、吹雪、小拉菲前排、初雪、基辅等）。

## Tip 奶与拐

奶和拐可以有效提高练级通过率，但要注意的是，上了奶和生存拐之后会降低全队输出，有超时风险。

此外，部分前排自奶船输出较低（如雪风、杰维斯），或不擅长应对重甲（如逸仙、明尼、新奥尔良），哪怕等级很高也可能存在超时风险，使用的时候要尤其注意。可考虑采用后置练级法练级，将这些自奶当做为后排遮风挡雨的“炮架子”。

## Tip. 誓约

再次提醒，誓约可以显著提高舰灵的伤害和减伤，以及开槽后可上更多装备，有效提高生存率。（这也是为什么前面提到好感度和经验同等重要）

## Tip 技能等级

提高技能等级可以显著提高舰灵的输出、奶量（如果有），但要注意，部分舰灵在提高技能等级后会更容易抢老板MVP，反而降低练级效率（例如Z1、埃罗芒什），因此要合理安排技能学习、合理安排打手（见“总纲篇-论老板和打手站位问题”）、或采用后置练级法。

## Tip.6 困难主线

困难主线也是优秀的练级点，推荐在以下点酌情练级：

16-3H（大井）、16-5H（北上、晓）

17-3H（深雪、晓、炮紫菜，难度高）、17-5H（晓、炮紫菜，难度高）

18-3H（反击、雷、设备紫菜）、18-5H（声望、飞机紫菜）

19-3H（镇海、设备紫菜）、19-5H（独角兽、飞机紫菜）

困难主线的优点是经验较多、通关时间不影响评级，缺点是17H索敌要求较高、星评级带路要求难满足、练度要求较高，且各个困难主线图均每日限定次。下面简单介绍一下在此练级的技巧：

①18-3H、18-5H、19-3H、19-5H推荐每天打满次；17-3H可以打捞到最强雷驱之一的深雪，没有的也推荐每天打满次；16-3H、16-5H的北上大井，签到活动有时会送，捞出一个开图鉴即可。

②17-3H每次掉落紫菜，17-5H、18H、19H为紫菜。

③这几张H图的练级门槛都较高，敌舰等级均在及以上，因此推荐把前文提到的从“老板-打手循环”毕业的80+级永恒好感舰灵拿来当打手。

④17-5H为重甲BOSS夕茉莉，主要输出手段是火海烫地板，索敌要求较高。选择鱼雷机航系+后排海伦娜能有效降低练级门槛。火海为百分比绝对真实伤害，且AI不会躲，没有回复的舰灵基本不可能吃满两个火海。因此推荐要么带奶、要么带高输出，在吃满两个火海前把她秒掉。（来自小强之王）

⑤如想选择低练度打手、或通关有其他困难的，可选择倍手操。

⑥19H可作为战巡通用的优质练级点，18H可作为轻巡通用的优质练级点。这些舰灵有练级需求的不容错过。

# 原理：
