# 练级与资源投入

最好的练级点不是别人表格里经验最高的那一关，而是你能稳定重复、收益符合当前目标、又不会挤掉重要活动预算的那一关。

## 先明确练谁

把舰灵分成三组：

- **当前主力**：负责继续推进，优先保证等级、技能和基础装备。
- **近期候补**：能补足主力缺少的职责，跟随培养但不抢核心资源。
- **远期收藏或专用角色**：先保留，等玩法需要时再投入。

如果当前主力还会频繁减员，同时培养大量远期角色只会让练级过程更慢。

## 评估一个练级点

连续记录几轮，比只看一轮结果更有用：

| 指标 | 要看什么 |
| --- | --- |
| 稳定性 | 自动作战是否会减员或偶发失败 |
| 时间 | 一轮耗时是否适合你的在线方式 |
| 消耗 | 燃料和其他消耗能否长期承担 |
| 经验 | 经验是否集中到真正要培养的舰灵 |
| 附带产出 | 掉落是否正好补充当前装备或材料 |

稳定性不够时，先降低难度或减少候补数量。稳定之后，再比较单位时间和单位燃料收益。

## 满编与低耗怎么选

开荒阶段的首要目标是继续解锁内容。主力队尚未成形时，为了追求极限低耗而频繁失败，往往得不偿失。

当主力已经稳定、目标变成长期打捞或练候补，才适合逐步减少编队规模，观察最低可接受配置。每减少一个位置，都要重新验证通关率、耗时和经验分配。

## 卡住时的调整顺序

1. 先看失败发生在生存还是输出；
2. 手动打一轮，确认自动战斗的问题；
3. 调整站位、技能与现有装备；
4. 只强化能解决瓶颈的项目；
5. 仍然不稳，再换练级点或更换舰灵。

社区旧攻略中的固定练级关卡、经验值和低耗阵容只作为历史线索。本站接入可复算数据集前，不把这些数字写成当前版本结论。
:::
