# 养成与资源

养成不是把所有可点击的按钮都点一遍。它的目标是用现有资源解决当前最明确的瓶颈。

## 先判断瓶颈

| 表现 | 优先检查 |
| --- | --- |
| 开场很快减员 | 等级、生存属性、站位、回复与防护 |
| 能站住但超时 | 主力技能、装备匹配、目标与输出覆盖 |
| 手动能过、自动不稳 | 操作路径、技能时机、容错 |
| 单次能过、重复成本太高 | 队伍规模、燃料、练级点与替代角色 |

## 推荐投入顺序

先让主力队达到稳定通关，再补自动作战的容错，最后才为低耗、活动或特殊机制建立分队。这个顺序会随账号情况变化，但“先解决当前问题”比照抄一份毕业清单更可靠。
