# 来源与版权

本站把“知道资料在哪里”和“可以公开使用资料”视为两件事。资产进入台账，不代表它已经取得公开许可。

## 来源优先级

1. 游戏内公告、官方网站和官方商店页；
2. 官方论坛或官方账号发布内容；
3. 有作者、日期和修订记录的 Wiki；
4. 可确认作者与发布时间的社区攻略；
5. 群文件、截图、转存文档等待核实资料。

涉及当前版本时，优先使用更接近游戏内状态的来源。社区资料可以提供实战方法，但角色强度、掉落和活动路线必须单独标记版本。

## 许可状态

| 状态 | 正文可用 | 素材可用 | 处理方式 |
| --- | --- | --- | --- |
| owned | 是 | 按登记范围 | 可发布并保留证据 |
| authorized | 是 | 按授权范围 | 记录授权对象和范围 |
| quoted | 可转述或短引用 | 否 | 链接原文，不搬运图片 |
| pending | 否 | 否 | 只进入内部审阅与隔离区 |
| restricted | 否 | 否 | 不进入公开构建 |

## 当前资料边界

《拂晓手册》整合目录中的 29 个源文件已经登记哈希、类型、更新时间和迁移状态，但作者、转载范围与素材许可仍待签核。现阶段允许：

- 在本地生成结构、数量和异常报告；
- 用它们规划目录和人工审核任务；
- 在页面来源区登记对应资产 ID。

<!-- article-paragraph:non-prose -->
现阶段不允许：

- 把源文段落改几个词后公开；
- 发布原图、截图、嵌入媒体或表格；
- 把待授权结论伪装成本站原创；
- 让待授权内容进入搜索索引或站点构建产物。

发现来源或授权信息有误时，请按[编辑与贡献规范](./contributing)提交更正。
