# 战斗攻略

一份能长期使用的战斗攻略，应该告诉你为什么这样打，以及条件变化后怎样改。

## 两条核心路径

- [活动推图方法](./event-maps)：先读规则、路线和奖励，再判断是否需要换队。
- [PVE 配队方法](./pve-team-building)：按敌人、职责、地图条件和成本选择舰灵。

## 进阶玩法

- [争锋竞技](./pvp-arena)：按赛季规则和海域限制安排长期养成。
- [遭遇战](./encounter)：围绕多队连续作战和总伤害调整阵容。
- [无尽海域](./endless-sea)：管理有限出击次数、BOX 深度与高层容错。

如果只想临时排查，也可以打开[PVE 选人速查](../topics/pve-selection)。
