# PVE 配队方法

配队不是把强度榜最上面的角色全部塞进同一队。它是在当前地图、当前目标和当前船坞之间做取舍。

## 先写清作战任务

同一支队伍很难同时做到开荒、高难、低耗打捞和练级。开始配队前，先选一个主要目标：

- 首次通关；
- 三星或任务条件；
- 稳定自动；
- 低耗重复；
- 携带候补练级；
- 处理特定敌人。

目标不同，阵容评价也会变。一次通关很强的满编队，不一定适合长时间打捞。

## 再看敌方压力

至少记录四项信息：

1. 敌方主要类型与分布；
2. 伤害集中在前排还是后排；
3. 是否有必须快速处理的目标；
4. 路线、舰种或任务限制。

不知道敌人怎样造成失败时，先手动观察一轮，不要立即更换全部角色。

## 给每个位置分配职责

一支完整队伍通常需要在以下职责中做组合：

| 职责 | 判断问题 |
| --- | --- |
| 前线生存 | 谁承受主要压力，是否会过早减员 |
| 稳定输出 | 谁能持续处理常规敌人 |
| 集中输出 | 谁负责关键目标或时间压力 |
| 回复与支援 | 是否需要治疗、增益、控制或减伤 |
| 条件适配 | 是否满足路线、舰种或任务要求 |
| 成本控制 | 重复作战时是否值得满编 |

角色可以同时承担多个职责，但不能只因为稀有度高就假定它适合当前关卡。

## 从能过到稳定，再到省

第一次组队时先保证通关。稳定之后按以下顺序缩减：

1. 找出几乎没有发挥作用的位置；
2. 一次只替换或减少一个位置；
3. 连续测试多轮；
4. 记录失败率、耗时和消耗；
5. 到达可接受边界后停止。

这比直接照抄“最低消耗阵容”更适合新人，因为你的等级、装备和操作条件通常与攻略作者不同。

## 微调时只改一个变量

- 生存不足：调整站位、防护、回复或手动操作。
- 理论输出够但实际不够：检查命中、目标、走位和技能空转。
- 持续输出不足：检查技能循环和主装备匹配。
- 路线不满足：先满足地图条件，再谈强度。

需要快速选人时，打开[PVE 选人速查](../topics/pve-selection)。
