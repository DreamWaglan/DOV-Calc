# 无尽海域配队方法

当前公开资料把无尽海域描述为一套需要预先选择舰灵 BOX、管理有限出击次数并逐层推进的玩法。单队强度重要，但舰灵储备、职责分配和测试纪律同样重要。

## 入场前先做 BOX 盘点

按职责而不是稀有度给舰灵做标记：

- 清理多目标；
- 处理单体目标；
- 前线生存；
- 回复与减伤；
- 输出增益；
- 特定弹种或护甲适配；
- 备用与补位。

公开攻略所述的当前规则包含 60 艘舰灵 BOX、每次 6 艘出击、每艘有限出击次数等限制。规则会随版本调整，进场前仍要以游戏内说明为准。

## 先用模拟战斗

官方版本说明已经加入通关后的模拟战斗支持。正式出击前，用模拟战斗确认：

- 队伍能否在时限内完成目标；
- 哪个位置最容易减员；
- 关键技能是否能正常锁定目标；
- 当前队伍是否值得消耗出击次数；
- 更高层是否需要保留同职责角色。

## 分层安排

低压层优先使用职责完整但不稀缺的队伍，把关键输出、强回复和专用角色留给明确需要它们的关卡。进入高压层后，输出与生存要同时考虑，不能把回复或减伤一律视为“占位置”。

## 失败后怎么改

1. 确认是输出不足、暴毙、锁定还是操作问题；
2. 只替换一个主要职责；
3. 在模拟战斗中重复验证；
4. 记录角色剩余次数与后续关卡需求；
5. 再决定是否正式出击。
