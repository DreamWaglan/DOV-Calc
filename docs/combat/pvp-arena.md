# 争锋竞技入门

争锋竞技是赛季化的跨服玩法。公开公告显示，赛季会设置多个海域，并可能加入稀有度限制、天气或其他规则。这里适合做长期养成规划，不适合只靠一张固定阵容图。

## 先读本赛季规则

进入编队前确认：

1. 本赛季开放哪些海域；
2. 每个海域的舰种或稀有度限制；
3. 天气、增益和减益如何生效；
4. 排名按什么结果结算；
5. 进攻编组与装备保存规则是否调整。

旧赛季里有效的队伍，换到新限制下可能无法出战。先确认入口说明和官方公告，再参考社区阵容。

## 新人怎样投入

不要为了短期排名同时重养三套半成品队伍。更稳妥的顺序是：

- 先选已有练度最高、规则允许的一组；
- 补足该组的生存、输出和关键支援；
- 再培养第二组，保证多个场次都有可用阵容；
- 装备优先服务实际出战队，不提前复制整套毕业装；
- 每次赛季变更后重新评估，不把旧排名当永久强度。

## 看回放时记录什么

- 输在开场减员、持续输出还是最后超时；
- 哪个位置没有完成预期职责；
- 敌方技能与我方技能是否错开；
- 装备和阵型是否真的适配当前海域；
- 同一问题能否通过一处小调整解决。
