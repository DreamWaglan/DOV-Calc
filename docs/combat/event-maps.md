# 活动推图方法

活动攻略通常展示作者的舰灵、装备和操作结果。你的船坞不同，最重要的不是照抄阵容，而是把攻略里的条件换算成自己的方案。

## 第一步：先确定这次要拿什么

活动常见目标包括首次通关、任务奖励、商店兑换、打捞和高难挑战。它们对队伍的要求并不相同。

- 只要首次通关：优先稳定，不必追求最低消耗。
- 需要重复刷取：再比较耗时、燃料和掉落。
- 追高难或 EX：先确认奖励是否值得额外养成。
- 活动即将结束：优先完成确定能拿到的目标。

## 第二步：读地图条件

进入关卡前，逐项看清：

1. 路线或带路条件；
2. 敌方舰种、属性与数量；
3. BOSS、死路和返航规则；
4. 当前队伍能否满足星级或任务条件；
5. 掉落与兑换是否仍符合本次目标。

公开商店的版本说明显示，活动编组、敌方图鉴和掉落列表等界面仍在持续调整。因此，旧截图只能用来理解方法，当前信息以游戏内界面为准。

## 第三步：把攻略拆成职责

不要先对角色名字。先看攻略中的每个位置负责什么：

- 承受前线伤害；
- 处理特定敌人；
- 提供回复或增益；
- 满足路线条件；
- 降低重复作战成本。

然后在自己的船坞里找能完成同一职责的替代者。具体做法见[PVE 配队方法](./pve-team-building)。

## 第四步：实战验证

先手动打一到三轮，观察失败点，再决定是否托管或重复作战。

- 路线不对：先修正条件，不要继续强化。
- 开场减员：处理生存和站位。
- 最后超时：处理输出覆盖与技能节奏。
- 偶发翻车：提高容错，再评估长期消耗。

::: warning 活动结论有效期短
具体低耗路线、掉落、临时加成和高难阵容只对当期活动负责。页面没有当期人工审核时，应把它当作决策流程，而不是现成答案。
:::
