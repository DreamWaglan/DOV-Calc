# 新手路线

这条路线不要求你记住一串关卡号，也不会先塞给你一张角色强度表。它先解决五个更实际的问题：

1. 这款游戏的战斗和养成在做什么；
2. 入坑后第一支队伍怎么成形；
3. 经验、装备和资源该怎样投入；
4. 活动地图上的条件该怎么看；
5. 卡关后究竟要换人、换装备，还是改操作。

## 推荐顺序

### 1. 先看懂游戏

阅读[游戏简介](./game-introduction)，分清即时操作、舰灵养成、装备和编队各自解决什么问题。

### 2. 再安排开局

[第一周行动指南](./first-week)按目标而不是按死板日期组织。即使你在活动中途入坑，也能照着调整。

### 3. 建立养成节奏

[练级与资源投入](../progression/leveling)会教你用通关稳定性、时间和消耗判断练级点，不把旧版本的固定地图当永久答案。

### 4. 学会读活动

[活动推图方法](../combat/event-maps)从路线条件、敌方信息和任务奖励出发，先判断规则，再套用攻略。

### 5. 最后学会调队

[PVE 配队方法](../combat/pve-team-building)不提供一份很快过期的唯一阵容，而是给出从敌人、任务到舰灵职责的完整判断顺序。

## 只想快速排查

- 今天不知道做什么：看[新手速查清单](../topics/new-player-checklist)。
- 不知道该养谁：看[PVE 选人速查](../topics/pve-selection)。
- 不知道装备怎么换：看[新手配装速查](../topics/beginner-equipment)。

::: warning 当前版本边界
角色强度、活动路线、掉落和资源优先级会随版本变化。正文只保留可复用的方法；涉及具体数值时，以游戏内说明和当期活动公告为准。
:::
