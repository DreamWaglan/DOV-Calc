# 入坑第一周行动指南

“第一周”不是七张必须按天打卡的清单。有人每天只玩半小时，也有人正好赶上活动。这里按结果分阶段：完成一个目标，再进入下一个。

## 目标一：让游戏先顺手

- 完成新手引导，熟悉移动、自动战斗、技能和暂停菜单。
- 检查画面、帧率、技能动画等设置，先解决发热、卡顿和误触。
- 认清首页的燃料、晶币、钻石等资源入口，但暂时不要凭感觉大量兑换。
- 查看当前公告和活动剩余时间。活动即将结束时，不要照搬长期开荒路线。

## 目标二：组出一支能推进的主力队

先用现有舰灵补齐基本职责，不必因为缺某个限定角色停在原地。

- 保留能承受前线压力的位置；
- 准备稳定输出，而不是只追求一次爆发；
- 有合适的回复或辅助就加入，没有也先保证队伍完整；
- 技能和装备先服务这支主力队；
- 卡关前不要同时铺开多支半成品队伍。

角色选择可以对照[PVE 选人速查](../topics/pve-selection)，配装则看[新手配装速查](../topics/beginner-equipment)。

## 目标三：用主线建立日常循环

主线推进的意义不只在通关奖励，还在于逐步开放养成和日常功能。每解锁一个系统，先弄清楚三件事：

1. 它消耗什么；
2. 它稳定产出什么；
3. 当前主力队是否真的需要。

当天结束前，完成已开放且回报明确的日常内容，再把剩余资源用于主线或练级。不要为了“清空所有红点”打乱主力队的养成顺序。

## 目标四：决定是否转入活动

活动值得投入多少，取决于剩余时间、通关能力和奖励需求。先读活动规则与路线条件，再用一支现有队伍试打。能够稳定完成目标，就安排重复作战；需要大幅重养整队才能进入，则先算清时间与资源。

详细判断见[活动推图方法](../combat/event-maps)。

## 第一周结束时，你应该得到什么

- 一支能继续推进的主力队；
- 一套知道“先查什么”的卡关方法；
- 对每日资源来源和主要消耗有基本认识；
- 能读懂活动页面，不会因为一份旧攻略盲目重养；
- 留有一部分未被冲动消费的稀缺资源。
