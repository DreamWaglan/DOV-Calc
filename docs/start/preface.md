# 阅读前说明

这份手册首先是一套“遇到问题能找到答案”的资料，不是要求从第一页背到最后一页的教科书。

## 怎么读最省时间

- 刚入坑：从[新手路线](./)连续读到 PVE 配队。
- 正在卡关：直接查看战斗页的排查顺序。
- 想核对结论：展开页面底部的来源与版本信息。
- 准备投稿：先读[编辑与贡献规范](../about/contributing)。

## 页面状态是什么意思

| 状态 | 含义 | 使用建议 |
| --- | --- | --- |
| 当前 | 已按页面所示版本核验 | 可以作为当前操作依据 |
| 草稿 | 结构可读，仍缺事实或版本审核 | 先用方法，具体数值另行核对 |
| 待复核 | 基线或来源发生变化 | 不要照搬旧结论 |
| 已归档 | 留作历史记录 | 只用于追溯 |

## Word 和长图如何进入 Wiki

本项目收到的 Word、表格和图片均已按授权资料登记。公开站点只发布审核台账标记为可公开使用的正文、数据与派生图片；原始下载文件仍保留在受控资料区，不作为站点附件直接分发。

公开页面会把长文拆成可导航章节，把长图整理为带说明和替代文本的图集，并为可核验事实登记来源、版本和复核日期。这样既保留资料脉络，也让后续维护者知道结论从哪里来、何时需要复核。
