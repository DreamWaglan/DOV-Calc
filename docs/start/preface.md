# 阅读前说明

这份手册首先是一套“遇到问题能找到答案”的资料，不是要求从第一页背到最后一页的教科书。

## 怎么读最省时间

- 刚入坑：从[新手路线](./)连续读到 PVE 配队。
- 正在卡关：直接查看战斗页的排查顺序。
- 想核对结论：展开页面底部的来源与版本信息。
- 准备投稿：先读[编辑与贡献规范](../about/contributing)。

## 页面状态是什么意思

| 状态 | 含义 | 使用建议 |
| --- | --- | --- |
| 当前 | 已按页面所示版本核验 | 可以作为当前操作依据 |
| 草稿 | 结构可读，仍缺事实或版本审核 | 先用方法，具体数值另行核对 |
| 待复核 | 基线或来源发生变化 | 不要照搬旧结论 |
| 已归档 | 留作历史记录 | 只用于追溯 |

## 为什么不直接搬 Word 和长图

现有资料中有一部分仍在确认作者、转载范围和素材许可。它们已经进入内部资产台账和审阅流程，但在许可明确前，不会复制到公开正文，也不会进入公开静态资源目录。

公开页面采用重新撰写的结构，并为可核验事实登记官方页、论坛帖或 Wiki 来源。这样既能保留资料脉络，也能让后续更新的人知道某个结论从哪里来、何时需要复核。
