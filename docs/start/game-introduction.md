# 这是什么游戏

《拂晓：胜利之刻》把舰灵收集养成和 3D 弹幕即时海战放在同一套循环里。你需要组建舰队、培养舰灵、配置装备，然后在战斗中控制走位、闪避和技能时机。

## 战斗不是只看面板

自动战斗能处理已经稳定通关的内容，但第一次挑战高压关卡时，走位与技能释放仍会改变结果。判断一次失败时，不要只看战力数字：

- 很快减员，先查生存、站位和敌方攻击方式；
- 时间不够，再查输出覆盖、技能节奏和目标选择；
- 自动打不过，可以手动观察真正的失误点；
- 同一队反复失败，才进入换人和重新配装。

## 编队解决的是职责分工

公开商店说明把舰队描述为主攻击群与辅助位置共同组成的队伍。不同舰种、技能和装备提供的不是单纯高低分，而是输出、生存、支援、路线适配等不同职责。

新人配队时先问“缺什么”，再问“谁最强”：

1. 谁能稳定站住；
2. 谁负责处理当前敌人；
3. 谁能提供回复、增益或控制；
4. 队伍是否满足地图条件；
5. 消耗是否适合重复作战。

## 养成是一个闭环

推图解锁内容，内容产出资源，资源再用于等级、技能、突破与装备。最常见的浪费不是某次强化选错，而是同时培养太多暂时用不到的舰灵，导致第一支主力队迟迟无法稳定通关。

因此，开局阶段先把资源集中到一支能推进的队伍。等主线和日常循环稳定，再为活动、低耗打捞或特殊敌人扩充第二套方案。
