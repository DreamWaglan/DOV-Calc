游戏简介

《拂晓》是一款舰灵题材的二次元海战养成手游。指挥官可收集并培养风格各异的舰灵少女，体验舰灵剧情、主题活动、舰灵养成、羁绊互动、换装收集等丰富内容。游戏持续推出新玩法与优化更新，并通过Q群、直播、社区活动等方式积极听取玩家建议。官方与玩家保持较高频率互动，社区氛围友好活跃，欢迎各位指挥官一同加入港区，开启属于自己的海上冒险之旅~

未来，《拂晓》还将推出新舰灵、新换装、新活动、新故事，并不断优化游戏体验~

也期待与各位指挥官继续并肩前行，共同书写更多属于《拂晓》的精彩故事~
