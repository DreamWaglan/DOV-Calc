# 新手速查清单

不知道接下来做什么时，从当前场景对应的小节开始，不必全部重做。

## 每次登录

- [ ] 查看游戏公告、活动剩余时间和版本变化。
- [ ] 领取已经完成的产出，不为了红点提前消费资源。
- [ ] 确认今天的主要目标：主线、练级、活动或材料。
- [ ] 检查主力队是否仍有技能、装备或等级的明显短板。

## 准备推图

- [ ] 读关卡目标、路线条件、敌方信息和掉落。
- [ ] 先用当前主力试打，不因旧攻略立即重养整队。
- [ ] 手动观察第一次失败发生在生存还是输出。
- [ ] 一次只调整一个主要变量，再比较结果。

## 准备养成

- [ ] 当前投入能否解决明确瓶颈。
- [ ] 主力队是否优先于远期收藏角色。
- [ ] 稀缺资源是否有更难替代的用途。
- [ ] 装备是暂用过渡，还是值得长期强化。

## 准备参加活动

- [ ] 先选首次通关、兑换、打捞或高难中的主要目标。
- [ ] 核对活动剩余时间和自己的可用资源。
- [ ] 把攻略阵容拆成职责，再找自己的替代角色。
- [ ] 稳定以后再压缩队伍与消耗。

## 下线前

- [ ] 处理即将到期的任务与活动目标。
- [ ] 安排已开放的长期产出或学习队列。
- [ ] 给明天保留必要的燃料和稀缺资源。
- [ ] 记录卡关点，避免第二天重新猜原因。
