# PVE 选人速查

先在自己的船坞里筛选，而不是先从榜单里找一个没有的角色。

## 五步筛选

1. **是否拥有**：常驻易得、当前可获取、暂时绝版要分开看。
2. **是否满足条件**：舰种、位置和地图限制必须先过。
3. **承担什么职责**：生存、持续输出、集中输出、回复、增益或控制。
4. **是否适配敌人**：攻击方式、目标覆盖和技能节奏是否匹配。
5. **培养成本是否合理**：已有等级、技能与装备往往比纸面上限更重要。

## 新人优先看什么

| 情况 | 选择方向 |
| --- | --- |
| 主线开荒 | 已拥有、容易成形、能稳定承担职责 |
| 活动首次通关 | 满足路线和任务条件，容错优先 |
| 长期打捞 | 稳定后再比较消耗和速度 |
| 高难挑战 | 针对敌方机制准备专用角色 |
| 练候补 | 主力能兜底，经验分配清楚 |

## 什么时候不要看稀有度

- 高稀有角色尚未完成关键养成；
- 低稀有角色已经能稳定完成当前职责；
- 地图条件限制了舰种；
- 队伍真正缺少的是回复、控制或生存；
- 为了一个短期目标投入的资源无法收回。

## 建议记录的角色卡字段

后续结构化角色页应至少记录：名称、舰种、获取状态、主要职责、适用敌人、培养门槛、版本、来源和核验状态。缺少版本与来源的推荐，不进入“当前”状态。

完整配队流程见[PVE 配队方法](../combat/pve-team-building)。
